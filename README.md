# 🏢 ListFlow AI — Real Estate Marketing Studio

An AI-powered marketing engine that generates 6 complete promotional channels and video scripts for real estate properties using Streamlit and Google Gemini.

## Features
- **Multimodal Inputs:** Accepts property specs, multiple photos, and walkthrough videos.
- **6 Output Channels:** MLS Listing, Instagram Caption, Facebook Post, Email Blast, WhatsApp Pitch, and Reel Script.
- **Single-Click Downloads:** Download individual channel text files or the entire marketing bundle at once.
